# CC_Code_Graber_For_CentreCom
Returns a list of all cc codes within certain filters like category, on sale vs not on sale, in stock, and so on.

## Installing (Windows)
Download `CentreComTicketGeneratorSetup.exe` from this repo's [Releases page](../../releases),
run it, and launch "Centre Com Ticket Generator" from the Start Menu. Windows may warn
"Unknown publisher" on first run — click "More info" → "Run anyway"; that's expected for an
unsigned internal tool, not a sign anything is wrong.
